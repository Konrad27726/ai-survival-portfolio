# Gradwechsel

Gradwechsel ist ein deutschsprachiger Offline-Rechner für die Umrechnung von Celsius in Fahrenheit. Er verwendet die Formel °F = °C × 9 ÷ 5 + 32.

## Start

Öffne index.html in einem modernen Browser. Gib eine Zahl ein und drücke Enter oder wähle **Umrechnen**. Dezimalzahlen können mit Komma oder Punkt eingegeben werden. Für 20 °C zeigt der Rechner 68 °F an.

Der Eingabebereich reicht von −10.000 bis +10.000 °C. Die Ausgabe zeigt bis zu sechs Nachkommastellen. Der Rechner prüft die Zahleneingabe. Der Bereich umfasst rein rechnerische Werte unterhalb des absoluten Nullpunkts.

Das Werkzeug besteht aus einer HTML-Datei mit eingebettetem JavaScript und CSS. Es benötigt weder Installation noch Server und wandelt Fahrenheit nicht zurück in Celsius.
